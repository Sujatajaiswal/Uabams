Gateway Upload Flow

Gateway creates a closed session folder, compresses it as a ZIP archive, and uploads it with HTTP PUT to /api/v1/archive.

Upload Endpoint PUT /api/v1/archive
Archive Name <gatewayId>__<trainId>__<sessionName>.zip
Metadata session_metadata.json only RMS, peak, fault, and raw files are binary .bin files.
Database MongoDB Atlas Cloud Storage

Cloud Data Contract

This cloud service receives complete gateway session archives, validates and parses the files, stores both raw and processed data, and returns HTTP status responses to the gateway.

Server Receives HTTP PUT /api/v1/archive with raw ZIP bytes named <gatewayId>__<trainId>__<sessionName>.zip, plus optional POST /api/v1/alert JSON alert events.
Server Processes session_metadata.json plus seven binary files: rms/rms_25cm.bin, peak/peak_50m.bin, faults/faults.bin, and raw/*.bin. RMS is parsed per about 25 cm segment; peak records are parsed per 50 m window.
Server Stores Original ZIP metadata, gateway payload, extracted file metadata, RMS records, peak records, fault records, raw packet metadata, and realtime alert events in MongoDB Atlas cloud storage.
Server Sends Back HTTP 201/200 after successful durable storage, HTTP 200 for duplicate archive, HTTP 422 for filename/metadata mismatch, and HTTP 4xx/5xx for upload or server errors.

ICD Archive Data Format

The gateway sends one ZIP archive. Only session_metadata.json is JSON; all other session files are binary .bin files.

File in ZIP Type Format Cloud Use
session_metadata.json JSON Gateway, train, firmware, session name, status, created UTC Identifies the uploaded session
rms/rms_25cm.bin Binary 70-byte fixed records, RMS values as float g Spatial acceleration data every 25 cm
peak/peak_50m.bin Binary 302-byte fixed records, peak values as float g Peak acceleration per 50 m window
faults/faults.bin Binary 75-byte fixed records Gateway and node fault reporting
raw/adxl_left.bin Binary Length-prefixed raw packet stream Left axle raw packet traceability
raw/adxl_right.bin Binary Length-prefixed raw packet stream Right axle raw packet traceability
raw/bogie.bin Binary Length-prefixed raw packet stream Bogie raw packet traceability
raw/encoder.bin Binary Length-prefixed raw packet stream Encoder speed/distance traceability
